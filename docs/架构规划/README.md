# 架构规划（分级组网方案）

> 面向"小型 → 中型 → 大型 → 超大型园区 → 数据中心"的五级演进路线，
> 每级给出可落地拓扑、地址规划与关键配置，并可直接在模拟器中复现：
>
> ```
> python main.py --scenario smb        # 或 web UI 顶部下拉选择
> ```
>

| L4 | [超大型园区](04-超大型园区.md) | 5000+ 人 | 双核心 + 多区域 | 每区域汇聚 VRRP | OSPF 区域互联 | 静态 |

## 核心设计原则（跨方案通用）

1. **网关与冗余的关系决定 VLAN 划分**
   - VRRP 共享网关要求该 VLAN 的 **L2 广播域同时覆盖两台冗余设备**（两台核心之间需 trunk 透传该 VLAN）。
   - 若接入仅单上联某台汇聚，则**每台汇聚独享一个用户 VLAN**（VLAN 与网关一一对应，互不重叠），无需 VRRP——避免"一个 VLAN 跨多台网关"的环路与漂移问题。
2. **核心层尽量纯 L3**：核心只做路由（routed /30 互连 + 动态路由），不放用户 VLAN（SVI/网关）。
3. **一台设备的两个端口绝不共用同一网关 IP**（同一接口 IP 只在单端口出现），服务器接入用独立 /30 路由段。
4. **P2P 互连用 /30**：每段 /30 由两端设备共享（一端 .1/.2 一端 .3/.4，掩码 /30），OSPF 邻居建立在共享网段上。
5. **分层 = 控制面与故障域分离**：接入故障只影响本接入，汇聚故障只影响本汇聚；核心冗余（双核心 + 双上联）兜底。
