# 压测 · 多路由器环网（收敛与规模验证）

场景：`stress`（`python main.py --scenario stress`，可带 `N` 参数；默认 64 台，另有带弦环模式）

## 用途

- 验证模拟器在大拓扑下的**构建速度与 OSPF 收敛能力**（虚拟时间批量仿真）。
- 验证**全网可达性**：环上任意两台路由器互 ping 通。

## 拓扑

- `N` 台华为路由器，每台 5 个口：
  - `GE0/0/0`：stub 网段（`10.{i//250}.{i%250}.1/30`），兼作 Router ID 来源。
  - 环网模式（默认）：`R_i.GE0/0/1 ↔ R_{i+1}.GE0/0/2`，每段 /30 = `10.200.i.0/30`。
  - 带弦环模式（`ring=False`）：另加 `R_i.GE0/0/3 ↔ R_{i+2}.GE0/0/4`，段 = `10.201.i.0/30`，缩短收敛直径。
- 全部设备运行 OSPF（单域），`settle(12s)` 后收敛。

## 地址规划

| 用途 | 网段 | 示例（i=0） |
|---|---|---|
| stub/RouterID | 10.0.0.0/16（每台 /30） | R0 GE0/0/0 = 10.0.0.1/30 |
| 环网链路 | 10.200.i.0/30 | R0=.1，R1=.2 |
| 带弦链路（可选） | 10.201.i.0/30 | R0=.1，R2=.2 |

## 运行与验证

```
python main.py --scenario stress        # 64 台环网
python main.py --scenario "stress:128"  # 128 台（load 透传参数，见 main.py 解析）
```

| 检查 | 命令 | 预期 |
|---|---|---|
| 邻居 | `display ospf peer` | 每台 2 个邻居（带弦环 4 个）Full |
| 全网通 | R0 `ping 10.0.1.0 目标` 等 | 环上任意互 ping 通 |
| 构建耗时 | 加载场景日志 | 64 台约 15s（含收敛 settle） |

## 说明

- 压测走**虚拟时间**（`World(realtime=False)`），协议事件由 `Scheduler` 快进，
  与真实时间解耦；规模增长主要受 `settle` 固定时长约束。
- 本场景回归覆盖在 `test_scenarios.py`（`stress` 项）。
- 想压测更大规模可改 `build_stress(n=...)` 直接调用。
