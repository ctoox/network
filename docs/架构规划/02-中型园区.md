# L2 · 中型园区（200-1000 人）

场景：`medium`（`python main.py --scenario medium`）

## 适用场景

多部门/多网段、200-1000 人。引入**双核心层**：核心做用户网关 + DHCP + 冗余（VRRP），接入仅做二层透传。

## 拓扑

```
                 双核心（华三 SW-C1 / SW-C2）
             ┌─────────┬─────────┐
             │  Vlanif10/20      │  VRRP 虚拟网关
             │  GE1/0/23,24  ────┼── 核心间 trunk（透传 VLAN 10,20）
             ├──┬────────┬───────┤
          GE1/0/1     GE1/0/2
             │           │
          ┌──┴──┐    ┌──┴──┐
          │SW-A1│    │SW-A2│    接入交换机（锐捷 RGOS）
          │GE0/1│    │GE0/1│    trunk {10,20}
          └┬┬┬──┘    └┬┬┬──┘
         PC0-2(vlan10)  PC3-5(vlan20)
```

- 核心：SW-C1/SW-C2 双机，核心间双链路 trunk（GE1/0/23、GE1/0/24 均透传 VLAN 10/20）。
- 接入：SW-A1/SW-A2 上联核心（trunk {10,20}），下挂终端按 VLAN 划分。
- 关键：**用户 VLAN 的 L2 域通过核心间 trunk 同时覆盖两台核心** → 两台核心的 `Vlanif10`/`Vlanif20` 同处一个广播域 → VRRP 才成立。

## 地址规划

| 对象 | 网段 | 网关（VRRP 虚拟） | 用途 |
|---|---|---|---|
| VLAN 10 | 10.0.10.0/24 | 10.0.10.254 | 办公（PC0-2） |
| VLAN 20 | 10.0.20.0/24 | 10.0.20.254 | 财务/研发（PC3-5） |
| 核心 Vlanif | — | — | C1=10.0.10.1/20.1，C2=10.0.10.2/20.2（真实地址，虚拟网关漂移在其上） |

DHCP 由核心提供，按入口 VLAN 选择地址池。

## 关键配置

```
# SW-C1 / SW-C2
vlan batch 10,20
interface GE1/0/23        # 核心间 trunk
 port link-type trunk
 port trunk allow-pass vlan 10,20
interface Vlanif10
 ip address 10.0.10.1 255.255.255.0   # C2 用 .2
 vrrp vrid 10 virtual-ip 10.0.10.254
 vrrp vrid 10 priority 120            # C1 为 VLAN10 Master
 dhcp select global
interface Vlanif20
 ip address 10.0.20.1 255.255.255.0   # C2 用 .2
 vrrp vrid 20 virtual-ip 10.0.20.254
 vrrp vrid 20 priority 100
 dhcp select global
ospf 1
 area 0.0.0.0
  network 10.0.10.0 0.0.0.255
  network 10.0.20.0 0.0.0.255

ip pool pool1
 network 10.0.10.0 mask 255.255.255.0
 gateway-list 10.0.10.254
ip pool pool2
 network 10.0.20.0 mask 255.255.255.0
 gateway-list 10.0.20.254
```

```
# SW-A1 / SW-A2（锐捷）
interface GigabitEthernet 0/1
 switchport mode trunk
 switchport trunk allowed vlan 10,20
interface GigabitEthernet 0/2
 switchport mode access
 switchport access vlan 10      # A2 上联口放 vlan 20
```

## 冗余原理

- **设备冗余**：VRRP 按 VLAN 分组。本方案中 C1 同时是 VLAN10 与 VLAN20 的 Master（优先级更高）；
  生产部署可错峰：`vlan10 master=C1, vlan20 master=C2`（各 `priority` 交错即可）。
- **链路冗余**：接入若双上联两台核心，VLAN 域天然跨两台核心，任意核心故障不断网。
  模拟器中 SW-A1/A2 单上联 C1，核心间 trunk 保证 VLAN 域覆盖 C2，C1 故障时 C2 通过
  核心间 trunk 仍能代答虚拟网关。

## 验证

| 检查 | 命令 | 预期 |
|---|---|---|
| DHCP | PC `ipconfig` | 10.0.10.x / 10.0.20.x 自动获取 |
| VRRP | C1/C2 `display vrrp` | C1=Master、C2=Backup（同组） |
| 邻居 | 核心 `display ospf peer` | Full/ - |
| 跨 VLAN | VLAN10 PC `ping 10.0.20.x` | 100% 通（经核心路由） |

## 扩展

终端规模或网段增多 → 核心放不下用户网关 → 演进到 [L3 大型企业](03-大型企业.md)（核心转纯 L3，网关下放到汇聚）。
