# L5 · 数据中心（Spine-Leaf 扁平）

场景：`datacenter`（`python main.py --scenario datacenter`）

## 适用场景

服务器规模 / 东西向流量为主的园区数据中心。**Spine-Leaf（叶脊）扁平架构**：
每台 Leaf 双上联所有 Spine，任意两台服务器之间路径数=Spine 数，全网 OSPF 收敛。

## 拓扑

```
              SPINE-1 ──── SPINE-2（华为核心路由器，相互独立）
              │  │  │  │    │  │  │  │
          /30 /30 /30 /30  /30 /30 /30 /30   每台 Leaf 双上联两台 Spine
              │  │  │  │    │  │  │  │
             LEAF-1 LEAF-2 LEAF-3 LEAF-4      锐捷 Leaf 交换机
           ┌──┴──┐ ┌──┴──┐ ┌──┴──┐ ┌──┴──┐
          SRV-1-1 SRV-1-2 ...            每台 Leaf 下挂 2 台服务器
          (独立 /30 路由段，Leaf 端口即网关)
```

- Spine：2 台华为核心路由器（SPINE-1/SPINE-2），**不互联**（独立冗余平面）。
- Leaf：4 台锐捷交换机，每台双上联两台 Spine（GE0/0↔SPINE-x、GE0/1↔SPINE-y）。
- 服务器：每台服务器独享一个 **/30 路由段**，Leaf 端口即服务器网关。

## 地址规划

Spine 侧（Spine S 的 GE0/0/J 连 Leaf J）：

| Spine | GE0/0/0 | GE0/0/1 | GE0/0/2 | GE0/0/3 |
|---|---|---|---|---|
| SPINE-1 | 10.254.0.1/30 | 10.254.1.1/30 | 10.254.2.1/30 | 10.254.3.1/30 |
| SPINE-2 | 10.254.0.5/30 | 10.254.1.5/30 | 10.254.2.5/30 | 10.254.3.5/30 |

Leaf 侧（Leaf I 双上联）：GE0/0=10.254.I.2/30（↔SPINE-1）、GE0/1=10.254.I.6/30（↔SPINE-2）。

服务器段（每台独立 /30）：

| Leaf | 端口 | 网关（Leaf 端口） | 服务器 |
|---|---|---|---|
| LEAF-1 | GE0/2 | 192.168.1.1/30 | SRV-1-1 = 192.168.1.2 |
| LEAF-1 | GE0/3 | 192.168.1.5/30 | SRV-1-2 = 192.168.1.6 |
| LEAF-2 | GE0/2 | 192.168.2.1/30 | SRV-2-1 = 192.168.2.2 |
| LEAF-2 | GE0/3 | 192.168.2.5/30 | SRV-2-2 = 192.168.2.6 |
| … | … | 依此类推 | 192.168.{I}.2 / .6 |

## 关键设计原则

1. **一台设备（Leaf）的两个端口绝不共用同一网关 IP**：每个服务器端口独立 /30，
   端口即三层接口。若把两个服务器塞进同一网段共享一个网关，会引入单网关 + L2 环路风险。
2. **Spine 不互联**：两台 Spine 是两条独立转发平面；Leaf 到 Spine 均等双上联，
   OSPF ECMP 等价负载。Spine 故障只损失一半路径，不丢通。
3. **服务器默认路由指向 Leaf 端口 IP**（无需在服务器上跑路由协议）。

## 关键配置

```
# SPINE-1
interface GE0/0/0
 ip address 10.254.0.1 255.255.255.252
interface GE0/0/1
 ip address 10.254.1.1 255.255.255.252
interface GE0/0/2
 ip address 10.254.2.1 255.255.255.252
interface GE0/0/3
 ip address 10.254.3.1 255.255.255.252
ospf 1
 area 0.0.0.0
  network 10.254.0.0 0.0.0.3
  network 10.254.1.0 0.0.0.3
  network 10.254.2.0 0.0.0.3
  network 10.254.3.0 0.0.0.3

# LEAF-1（锐捷）
interface GigabitEthernet 0/0
 ip address 10.254.0.2 255.255.255.252
interface GigabitEthernet 0/1
 ip address 10.254.0.6 255.255.255.252
interface GigabitEthernet 0/2
 ip address 192.168.1.1 255.255.255.252
interface GigabitEthernet 0/3
 ip address 192.168.1.5 255.255.255.252
router ospf 1
 network 10.254.0.0 0.0.0.3 area 0
 network 10.254.0.4 0.0.0.3 area 0
 network 192.168.1.0 0.0.0.3 area 0
 network 192.168.1.4 0.0.0.3 area 0
```

## 验证

| 检查 | 命令 | 预期 |
|---|---|---|
| 邻居 | Spine/Leaf `show ip ospf neighbor` | 每 Spine 4 邻居、每 Leaf 2 邻居，Full |
| 东西向 | SRV-1-1 `ping 192.168.4.6`（Leaf4 下服务器） | 通（经 Spine） |
| 双平面 | 断开 SPINE-1 后跨 Leaf ping | 仍通（走 SPINE-2） |

## 扩展

- Spine 口不够 → 增加 Spine（3+ 台全互联，仍不互连，Leaf 等增上联口）。
- Leaf 下服务器增多 → 接入 Leaf 下加 ToR 交换机，ToR 双上联 Leaf，/30 段下沉。
