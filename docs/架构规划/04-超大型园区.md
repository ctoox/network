# L4 · 超大型园区（5000+ 人）

场景：`campus`（`python main.py --scenario campus`）

## 适用场景

多园区/多业务域（办公、研发、生产）隔离，5000+ 人。在 L3 基础上**按区域拆分汇聚对**，
每区域一套"双汇聚 + VRRP"，共享一对核心，OSPF 互联。

## 拓扑

```
                     CORE-1 ─────/30──── CORE-2        华为双核心（纯 L3）
                    │  │  │   │      │  │  │   │
               /30  /30 /30 /30  /30  /30 /30 /30     每区域 4 条上联（双汇聚×双核心）
            ┌──────┐  │    │        ┌──────┐  │
        AGG-A ◄────┼──┼────┼────────►AGG-B           区域 N 双汇聚（华三），VRRP 网关
        (GE1/0/1↔C1, GE1/0/2↔C2)     (GE1/0/1↔C1, GE1/0/2↔C2)
        Vlanif{10/20/30}              Vlanif{10/20/30}
          │ GE1/0/24 (trunk {vlan})     │ GE1/0/24
        终端                             终端
```

- 核心：CORE-1/CORE-2（华为），核心间 /30 互连（10.255.0.0/30），无用户 VLAN。
- 区域：3 个业务域——办公(zone1)、研发(zone2)、生产(zone3)，各一套双汇聚 AGG-A/AGG-B（华三）。
- 每台汇聚**双上联两台核心**（专用核心端口），4 条上联全部独立 /30，OSPF 全网互联。
- 区域内部：**VRRP 双机共享网关**（该方案中区域 VLAN 的 L2 域经汇聚间业务网段覆盖两台汇聚，
  故 VRRP 成立）。

## 地址规划

| 区域 | VLAN | 用户网段 | 虚拟网关（VRRP） | 汇聚真实地址 |
|---|---|---|---|---|
| 办公 | 10 | 10.1.10.0/24 | 10.1.10.254 | AGG-A=10.1.10.1，AGG-B=10.1.10.2 |
| 研发 | 20 | 10.2.20.0/24 | 10.2.20.254 | AGG-A=10.2.20.1，AGG-B=10.2.20.2 |
| 生产 | 30 | 10.3.30.0/24 | 10.3.30.254 | AGG-A=10.3.30.1，AGG-B=10.3.30.2 |

互联段：核心间 10.255.0.0/30；区域 Z 四条上联（以办公区为例）：

| 链路 | 核心端 | 汇聚端 |
|---|---|---|
| AGG-A↔CORE-1 | CORE-1 GE0/0/1 = 10.255.1.1/30 | AGG-A GE1/0/1 = 10.255.1.2/30 |
| AGG-A↔CORE-2 | CORE-2 GE0/0/1 = 10.255.1.9/30 | AGG-A GE1/0/2 = 10.255.1.10/30 |
| AGG-B↔CORE-1 | CORE-1 GE0/0/2 = 10.255.1.3/30 | AGG-B GE1/0/1 = 10.255.1.4/30 |
| AGG-B↔CORE-2 | CORE-2 GE0/0/2 = 10.255.1.11/30 | AGG-B GE1/0/2 = 10.255.1.12/30 |

（研发/生产区以 10.255.2/3.x 递增，规则相同。）

## 关键配置（以办公区为例）

```
# CORE-1
interface GE0/0/0
 ip address 10.255.0.1 255.255.255.252
interface GE0/0/1
 ip address 10.255.1.1 255.255.255.252
interface GE0/0/2
 ip address 10.255.1.3 255.255.255.252
ospf 1
 area 0.0.0.0
  network 10.255.0.0 0.0.0.3
  network 10.255.1.0 0.0.0.3
  network 10.255.1.2 0.0.0.3

# AGG-A（办公区）
vlan 10
interface Vlan-interface10
 ip address 10.1.10.1 255.255.255.0
 vrrp vrid 10 virtual-ip 10.1.10.254
 vrrp vrid 10 priority 110
interface GE1/0/1
 ip address 10.255.1.2 255.255.255.252
interface GE1/0/2
 ip address 10.255.1.10 255.255.255.252
interface GE1/0/24
 port link-type trunk
 port trunk permit vlan 10
ospf 1
 area 0.0.0.0
  network 10.1.10.0 0.0.0.255
  network 10.255.1.0 0.0.0.3
  network 10.255.1.8 0.0.0.3
```

## 冗余原理

- **核心**：双核心 + 双上联，核心链路/设备故障由 OSPF 收敛兜底。
- **区域**：双汇聚 + VRRP，汇聚设备故障虚拟网关不漂移；双上联核心防链路单点。
- **区域隔离**：办公/研发/生产各占独立 VLAN 与汇聚对，路由可达但 L2 隔离（利于后续 ACL/安全策略）。

## 验证

| 检查 | 命令 | 预期 |
|---|---|---|
| 区域内 | 办公PC `ping 10.1.10.x` | 通 |
| 跨区 | 办公PC `ping 10.3.30.x` | 通（CORE 转发） |
| VRRP | 每区 AGG `display vrrp` | A=Master、B=Backup |
| 邻居 | 核心 `display ospf peer` | 8 个邻居全部 Full |
| 冗余 | 断开 AGG-A↔CORE-1 后跨区 ping | 仍通 |

## 扩展

- 区域可继续水平扩展（每区 4 条上联 + 2 个核心口）；核心端口不足 → 增加核心对（多 Spine）。
- 生产区可改服务器接入 → 演进到 [L5 数据中心](05-数据中心.md) 的 Leaf 上联模型。
