# L3 · 大型企业（1000-5000 人）

场景：`large`（`python main.py --scenario large`）

## 适用场景

多楼栋/多分区、1000-5000 人。标准**核心-汇聚-接入 三层架构**：
核心纯 L3 骨干，汇聚做用户网关，接入纯二层。

## 拓扑

```
              CORE-1 ────/30──── CORE-2        华为核心（纯 L3 骨干，只跑 OSPF）
               │  \              │  \
           /30   \/30        /30  \/30
           │      \             │    \
         AGG-1 ───────/30──── AGG-2         华三汇聚（用户 VLAN 网关）
         (Vlanif10)              (Vlanif20)
           │ GE1/0/24            │ GE1/0/24
           │ trunk {10}          │ trunk {20}
         ACC-1 (vlan10)         ACC-2 (vlan20)     锐捷接入
         │  │  │  │             │  │  │  │
        PC0 PC1 PC2 PC3        PC4 PC5 PC6 PC7
```

- 核心：CORE-1/CORE-2（华为 VRP），**不放任何用户 VLAN**，仅路由 /30 互连 + OSPF。
- 汇聚：AGG-1/AGG-2（华三），**每台汇聚独享一个用户 VLAN 并充当其网关**：
  - AGG-1：`Vlanif10 = 10.0.10.1/24`（VLAN 10 的网关）
  - AGG-2：`Vlanif20 = 10.0.20.2/24`（VLAN 20 的网关）
  - **无 VRRP**——因为接入单上联各自汇聚，VLAN 与网关一一对应、不跨设备，无需冗余组。
- 每台汇聚**双上联两台核心**（AGG-1 的 GE1/0/1→CORE-1、GE1/0/2→CORE-2），链路冗余。

## 地址规划

| 段 | 网段 | 网关 | 说明 |
|---|---|---|---|
| VLAN 10（用户） | 10.0.10.0/24 | 10.0.10.1 | AGG-1 Vlanif10 |
| VLAN 20（用户） | 10.0.20.0/24 | 10.0.20.2 | AGG-2 Vlanif20 |
| 核心间 | 10.1.0.0/30 | — | CORE-1=.1，CORE-2=.2 |
| CORE-1↔AGG-1 | 10.1.0.4/30 | — | CORE-1=.5，AGG-1=.6 |
| CORE-1↔AGG-2 | 10.1.0.8/30 | — | CORE-1=.9，AGG-2=.10 |
| CORE-2↔AGG-1 | 10.1.1.0/30 | — | CORE-2=.1，AGG-1=.2 |
| CORE-2↔AGG-2 | 10.1.1.4/30 | — | CORE-2=.5，AGG-2=.6 |

终端静态配置：VLAN 10 下 10.0.10.2~.5（gw 10.0.10.1），VLAN 20 下 10.0.20.x（gw 10.0.20.2）。

## 关键配置

```
# CORE-1（核心纯 L3；CORE-2 同理，仅 IP 不同）
interface GE0/0/0
 ip address 10.1.0.1 255.255.255.252
interface GE0/0/1
 ip address 10.1.0.5 255.255.255.252
interface GE0/0/2
 ip address 10.1.0.9 255.255.255.252
ospf 1
 area 0.0.0.0
  network 10.1.0.0 0.0.0.3
  network 10.1.0.4 0.0.0.3
  network 10.1.0.8 0.0.0.3

# AGG-1（汇聚 = 用户网关）
vlan 10
interface Vlan-interface10
 ip address 10.0.10.1 255.255.255.0
interface GE1/0/1
 ip address 10.1.0.6 255.255.255.252
interface GE1/0/2
 ip address 10.1.1.2 255.255.255.252
interface GE1/0/24
 port link-type trunk
 port trunk permit vlan 10
ospf 1
 area 0.0.0.0
  network 10.0.10.0 0.0.0.255
  network 10.1.0.4 0.0.0.3
  network 10.1.1.0 0.0.0.3
```

## 冗余原理

- **链路冗余**：汇聚双上联核心；汇聚↔核心任一条链路中断，OSPF 立即收敛走另一条。
- **设备冗余**：核心双机 + OSPF ECMP/重收敛；汇聚单点（本方案每汇聚承载独立业务域，故障仅影响本域）。
- **故障域隔离**：VLAN 10 与 VLAN 20 的 L2 域互不重叠，杜绝广播风暴跨域扩散。

## 验证

| 检查 | 命令 | 预期 |
|---|---|---|
| 邻居 | 核心/汇聚 `display ospf peer` | 全部 Full/ - |
| 核心路由 | `display ip routing-table` | 核心只含路由 /30 + OSPF，无用户 Vlanif |
| 同区互通 | PC0 `ping 10.0.10.3` | 通（二层） |
| 跨区互通 | PC0 `ping 10.0.20.3` | 通（经 AGG-1→CORE→AGG-2） |
| 冗余 | 断开 AGG-1→CORE-1 后 PC ping | 仍通（走 CORE-2） |
