# L1 · 小型办公室（≤100 人）

场景：`smb`（`python main.py --scenario smb`）

## 适用场景

单办公区、单网段、≤100 人、几条专线/宽带出口。无独立核心层，**边界安全设备（防火墙）即全网网关**。

## 拓扑

```
              ISP (203.0.113.2)
                    │
             ┌──────┴──────┐
             │   FW1       │  华为 USG6000（防火墙）
             │  GE1/0/1    │  203.0.113.1/30（untrust，NAT 出口）
             │  GE1/0/0    │  10.0.10.254/24（trust，全网网关）
             └──────┬──────┘
                    │ GE1/0/23 (access vlan 10)
             ┌──────┴──────┐
             │   SW-A1     │  华三 接入交换机
             │ GE1/0/24 ───┼── trunk vlan 10 ── SW-A2 GE1/0/24
             └──┬────┬─────┘
            PC0  PC1        PC2  PC3
```

- 接入：2 台华三接入交换机级联（trunk 透传 VLAN 10），下挂终端。
- 边界：华为 USG6000 防火墙，`GE1/0/0` 接内网（trust）、`GE1/0/1` 接 ISP（untrust）。

## 地址规划

| 对象 | 网段/地址 | 说明 |
|---|---|---|
| 用户 VLAN 10 | 10.0.10.0/24 | 全网唯一用户网段 |
| 网关 | 10.0.10.254 | FW1 GE1/0/0 |
| 终端 | 10.0.10.2 ~ .5 | PC0..PC3，静态配置 |
| FW-ISP | 203.0.113.0/30 | FW1 GE1/0/1 = .1，ISP = .2 |

## 关键配置

```
# FW1
interface GE1/0/0
 ip address 10.0.10.254 255.255.255.0
interface GE1/0/1
 ip address 203.0.113.1 255.255.255.252
 ip route-static 0.0.0.0 0 203.0.113.2
 nat outbound 3001

# SW-A1 / SW-A2
vlan 10
interface GE1/0/24
 port link-type trunk
 port trunk allow-pass vlan 10
interface GE1/0/1
 port link-type access
 port default vlan 10

# PC
ip 10.0.10.x 255.255.255.0 gw 10.0.10.254
```

## 冗余与安全

- **冗余**：接入双机级联仅防单点断网；网关单点（防火墙），必要时升级 L2 方案（防火墙双机主备）。
- **安全**：防火墙默认拒绝、按需放行（`security-policy`）；出口 NAT overload 隐藏内网。
- 安全策略示例：

```
security-policy
 rule name internet
  source-zone trust
  destination-zone untrust
  action permit
```

## 验证

| 检查 | 命令 | 预期 |
|---|---|---|
| 全网互通 | 任意 PC `ping 10.0.10.x` | 100% 通 |
| 出口 | PC `ping 203.0.113.2` | 经 NAT 通 |
| NAT 会话 | FW `display nat session` | 可见 10.0.10.x -> 203.0.113.1 翻译 |
