# 信创 · 全国产组网实施方案

场景：`xinchuang`（`python main.py --scenario xinchuang`）

## 拓扑

```
              ISP (203.0.113.2)
                    │
             ┌──────┴──────┐
             │   FW-GW     │  华为 USG6000 防火墙
             │  GE1/0/1    │  203.0.113.1/30（untrust，NAT 出口）
             │  GE1/0/0    │  10.99.0.254/30（trust，↔核心）
             └──────┬──────┘
                    │
          Kylin-CORE-1 ──/30── Kylin-CORE-2     华为核心（纯 L3 + OSPF）
               │                      │
              /30                    /30
               │                      │
          NEOS-AGG-1              NEOS-AGG-2      华三汇聚（VLAN 网关）
          Vlanif10=10.0.10.1      Vlanif20=10.0.20.2
               │                      │
            GE1/0/24 trunk{10}    GE1/0/24 trunk{20}
               └────────┬─────────┘
                      RG-ACC-1                锐捷接入（双上联，每口单 VLAN）
               │  │   │  │
           KylinPC0-1     KylinPC2-3
           (vlan10)       (vlan20)
```

- 边界：华为 USG（FW-GW）安全域隔离 + 安全策略 + NAT，接核心与 ISP。
- 核心：Kylin-CORE-1/2（华为 VRP），核心间与到汇聚全部 /30 路由 + OSPF，无用户 VLAN。
- 汇聚：NEOS-AGG-1/2（华三），**每台汇聚独享一个用户 VLAN 网关**（同 L3 设计，无 VRRP）。
- 接入：RG-ACC-1（锐捷）**双上联两台汇聚**，但每根上联只透传一台汇聚的 VLAN
  （GE0/1 trunk{10}↔AGG-1、GE0/2 trunk{20}↔AGG-2）——VLAN 域不跨汇聚，避免环路。
- 终端：麒麟 PC 静态接入 VLAN 10/20。

## 地址规划

| 对象 | 网段/地址 | 说明 |
|---|---|---|
| FW↔CORE-1 | 10.99.0.252/30 | FW=10.99.0.254，CORE-1=10.99.0.253 |
| CORE-1↔CORE-2 | 10.99.0.0/30 | CORE-1=.1，CORE-2=.2 |
| CORE-1↔AGG-1 | 10.99.0.4/30 | CORE-1=.5，AGG-1=.6 |
| CORE-2↔AGG-2 | 10.99.0.8/30 | CORE-2=.9，AGG-2=.10 |
| VLAN 10（用户） | 10.0.10.0/24 | 网关 10.0.10.1（AGG-1 Vlanif10），KylinPC0-1 |
| VLAN 20（用户） | 10.0.20.0/24 | 网关 10.0.20.2（AGG-2 Vlanif20），KylinPC2-3 |
| FW↔ISP | 203.0.113.0/30 | FW=.1，ISP=.2 |

## 关键配置

```
# FW-GW（华为 USG）
interface GE1/0/0
 ip address 10.99.0.254 255.255.255.252
interface GE1/0/1
 ip address 203.0.113.1 255.255.255.252
 ip route-static 0.0.0.0 0 203.0.113.2
 ip route-static 10.0.0.0 16 10.99.0.253
 nat outbound 3001
firewall zone untrust
 add interface GE1/0/1
firewall zone trust
 add interface GE1/0/0
security-policy
 rule name internet
  source-zone trust
  destination-zone untrust
  action permit

# Kylin-CORE-1（华为 VRP；CORE-2 同理仅 IP 不同）
interface GE0/0/0
 ip address 10.99.0.253 255.255.255.252
interface GE0/0/1
 ip address 10.99.0.1 255.255.255.252
interface GE0/0/2
 ip address 10.99.0.5 255.255.255.252
ospf 1
 area 0.0.0.0
  network 10.99.0.252 0.0.0.3
  network 10.99.0.0 0.0.0.3
  network 10.99.0.4 0.0.0.3

# NEOS-AGG-1（华三）
vlan 10
interface Vlan-interface10
 ip address 10.0.10.1 255.255.255.0
interface GE1/0/1
 ip address 10.99.0.6 255.255.255.252
interface GE1/0/24
 port link-type trunk
 port trunk permit vlan 10
ospf 1
 area 0.0.0.0
  network 10.0.10.0 0.0.0.255
  network 10.99.0.4 0.0.0.3

# RG-ACC-1（锐捷，双上联各透传单 VLAN）
interface GigabitEthernet 0/1
 switchport mode trunk
 switchport trunk allowed vlan 10
interface GigabitEthernet 0/2
 switchport mode trunk
 switchport trunk allowed vlan 20
interface GigabitEthernet 0/3
 switchport mode access
 switchport access vlan 10
```

## 冗余与安全

- **冗余**：双核心 + 汇聚双上联（AGG-1 上 CORE-1、AGG-2 上 CORE-2），任一条链路中断由 OSPF 收敛；
  接入到两台汇聚的冗余在链路层面（VLAN 域严格隔离，不做跨汇聚 VLAN 透传）。
- **安全（等保要点）**：
  1. 安全域划分：trust（内网）/ untrust（外网）分离，策略默认拒绝、按需放行；
  2. 出口 NAT 隐藏内网地址；
  3. 内网静态路由回程（`10.0.0.0/16 → 核心`），外网默认路由出向（`0.0.0.0/0 → ISP`）。

## 验证

| 检查 | 命令 | 预期 |
|---|---|---|
| OSPF | 核心/汇聚 `display ospf peer` | 全部 Full/ - |
| 区内互通 | KylinPC0 `ping 10.0.10.3` | 通 |
| 跨区互通 | KylinPC0 `ping 10.0.20.3` | 通（AGG-1→CORE→AGG-2） |
| 出网 | KylinPC0 `ping 203.0.113.2` | 通（经 FW 安全策略 + NAT） |
| NAT | FW `display nat session` | 可见内网→203.0.113.1 翻译 |
| 安全策略 | 收紧策略后再 ping 外网 | 被丢弃（ACL 引擎生效） |

## 扩展

- 业务域增多 → 增加汇聚对与 VLAN（复用 [L4 超大型园区](../架构规划/04-超大型园区.md) 区域模型）。
- 需互联网高可用 → 双防火墙 + VRRP/双机热备；需内网纵深防御 → 增加国产 IPS/WAF 串接。
