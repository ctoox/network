# 信创 · 全国产化组网方案

> 面向党政机关、事业单位与国企的**信息技术应用创新（信创）**改造：
> 网络设备、安全设备、终端操作系统全部采用国内自主可控产品，并满足等级保护对边界防护的要求。
> 方案已在 NetSim 中完整构建并验证互通：`python main.py --scenario xinchuang`。

## 设备栈（全国产）

| 层级 | 设备 | 模拟器厂商 | 说明 |
|---|---|---|---|
| 边界安全 | 华为 USG6000 防火墙 | `HUAWEI_FW` | 安全域 + 策略 + NAT 出口 |
| 核心层 | 华为 AR/S 系列 | `HUAWEI` | 麒麟核心（Kylin-CORE） |
| 汇聚层 | 华三 S 系列 | `H3C` | NEOS-AGG，用户 VLAN 网关 |
| 接入层 | 锐捷 RG-S 系列 | `RUIJIE` | RG-ACC，二层透传 |
| 终端 | 麒麟操作系统终端 | `HOST`（华为 CLI） | KylinPC |

> 覆盖国产网络设备主要厂商（华为/华三/锐捷）与国产安全设备（华为 USG）；
> 终端侧麒麟桌面与服务器的国产 CPU（鲲鹏/飞腾/龙芯/兆芯）生态不在模拟范围，以 Host 终端代替。

## 方案特点

- **全部设备国产**：核心（华为）、汇聚（华三）、接入（锐捷）、安全（华为 USG）、终端（麒麟）。
- **边界安全**：USG 防火墙做安全域隔离（trust/untrust）+ 安全策略 + 出口 NAT。
- **核心纯 L3**：双核心只跑路由 /30 + OSPF，不放用户 VLAN，可水平扩展。
- **汇聚独享 VLAN 网关**（同 [L3 大型企业](../架构规划/03-大型企业.md) 设计）：接入单上联，
  VLAN 与网关一一对应，无需 VRRP。
- **等保合规思路**：边界安全域划分、访问控制策略、最小权限放行、出口 NAT 隐藏内网。

## 国产化替代路线（网络域建议）

1. **终端优先**：麒麟 OS + 国产 CPU 替换存量 PC（对网络无感知）。
2. **边界安全**：防火墙/入侵防御替换为国产（华为 USG、深信服 AF 等），划分安全域。
3. **核心-汇聚-接入**：按"先接入、后汇聚、再核心"分批替换为国产设备；双核心冗余保业务连续。
4. **管理与运维**：统一 NMS（华三 iMC / 锐捷 RG-BI）、合规审计、双机热备。
